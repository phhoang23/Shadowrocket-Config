# Shadowrocket Config

Cấu hình Shadowrocket dành cho iOS, tổng hợp các quy tắc và script hỗ trợ tùy chỉnh trải nghiệm sử dụng ứng dụng.

## Features

- YouTube: Ad Blocking
- Spotify: Script Customization
- Locket: Script Customization
- Sub-Store: Subscription Management
- URL Rewrite & MITM Rules

## Installation

1. Cài đặt Shadowrocket trên iOS.
2. Sao chép link cấu hình bên dưới.
3. Mở Shadowrocket và vào mục Config.
4. Nhập cấu hình từ URL.
5. Chọn cấu hình vừa nhập để sử dụng.

## Configuration URL
